Get the YOLO comparison run ID:
@'
import mlflow
from mlflow.tracking import MlflowClient

mlflow.set_tracking_uri("sqlite:///mlflow.db")
client = MlflowClient()

experiment = client.get_experiment_by_name("intelligent-video-analytics")

runs = client.search_runs(
    experiment_ids=[experiment.experiment_id],
    max_results=100
)

for run in runs:
    if run.info.run_name == "yolo-penn-fudan":
        print("Run ID:", run.info.run_id)
        print("Status:", run.info.status)
        print("Source Run ID:", run.data.tags.get("source_run_id"))
        print("---")
'@ | python


Problems & Solutions:

Problem 1: Encountered CUDA out-of-memory error when training RF-DETR.
Solution 1: RF-DETR supports contructor-level gradient checkpointing, which reduces activation memory at the cost of additional computation.
Example:
Before: model = RFDETRNano()
After: model = RFDETRNano(gradient_checkpointing=True)

Problem 2: While training, validating, and recording the results on MLflow for both the YOLOn and the RF-DETR nano, I noticed that both models name their metrics differently.
Solution 2: Created scripts backfill_rfdetr_mlflow.py and backfill_yolo_mlflow.py, where I pass the Run ID and the csv files that contain the metrics and corresponding values.
